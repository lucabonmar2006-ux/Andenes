# Carpeta de audios para Andenes
Colocá aquí los archivos de audio en formato MP3 para el reproductor flotante:

- `amor-interminable.mp3`
- `para-ser-libre.mp3`
- `por-el-sueldo.mp3`
- `luz-de-madrugada.mp3`
- `desde-lo-lejos.mp3`

El reproductor seleccionará uno de estos temas de manera aleatoria cada vez que alguien entre o actualice la página.
